# NHK Training Village Solar TV
The APK opens the provided Huawei FusionSolar station Overview on Android TV and Google TV without an intermediate portal screen. It does not bypass Huawei sign-in.
Use the remote MENU key or BACK key to configure a Huawei-authorized kiosk URL or open in an installed browser.
The app keeps the display on while active and retains WebView cookies. No password is embedded. Build with GitHub Actions, then download the NHK-Solar-TV-APK artifact.
