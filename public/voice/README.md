# เสียงพากย์เกม AI ต้นฉบับ 15 ข้อ

ใช้เสียง MP3 จริงที่ผู้ใช้ส่งมาเมื่อ 13 ตุลาคม 2026 สำหรับคำถามและตัวเลือก A/B/C
เว็บต้องเล่นไฟล์เสียงจาก Cloudflare โดยตรง ไม่บังคับผู้สอนนำเข้าเสียงซ้ำทุกเครื่อง

## วิธีติดตั้งครั้งเดียว

อัปโหลดไฟล์ AI_Game_Official_15_Recordings.zip เข้าโฟลเดอร์ public/voice ของสาขา audio-15-web
ZIP มี Q01.mp3–Q15.mp3 และ manifest.json
Build ใช้คำสั่ง node scripts/install-recorded-voice.mjs --required เพื่อแตกไฟล์
ไฟล์ทุกข้อผ่าน SHA256 เทียบต้นฉบับที่ผู้ใช้แนบมา
เว็บสร้าง /voice/manifest.json และ /voice/Q01.mp3 ถึง /voice/Q15.mp3
จอผู้สอนจะโหลดเสียงที่มีอยู่บนเว็บให้อัตโนมัติ
ถ้าไม่มีไฟล์ต้นฉบับ ขั้น Deploy จะหยุดก่อนเผยแพร่ เพื่อไม่ให้เว็บเงียบอีก

ZIP ไม่ใช่ไฟล์ที่จะให้ผู้สอนนำเข้าในห้องเรียน แต่ติดตั้งในเว็บไซต์ครั้งเดียว
หลังติดตั้งผู้สอนเพียงเปิดเว็บ เล่นเสียงต้นฉบับจริงได้ทันที
