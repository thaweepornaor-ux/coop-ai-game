# เสียงพากย์เกม AI – Q01 ถึง Q15

## วิธีใช้บนเว็บไซต์ (ไม่ต้องเพิ่ม MP3 ลง GitHub)

1. ดาวน์โหลด ZIP ที่แยก Q01.mp3–Q15.mp3 จากแชต ChatGPT นี้
2. แตก ZIP และเปิดเว็บไซต์ **จอผู้สอน** บนคอมพิวเตอร์ที่ต่อเครื่องเสียงห้องเรียน
3. คลิก **🎙 นำเข้าเสียง 15 ข้อ** ที่แถบเมนูด้านบน
4. เลือก MP3 ครบ 15 ไฟล์พร้อมกัน (Q01.mp3 ถึง Q15.mp3)
5. เมื่อเห็น **🎙 เสียงพากย์ 15 ข้อพร้อม ✓** ให้ทดสอบเสียงแล้วเริ่มเกม

ไฟล์จะเก็บใน IndexedDB ของเบราว์เซอร์บนเครื่องที่นำเข้า ไม่ถูกส่งไปเก็บบนเซิร์ฟเวอร์หรือ GitHub (หากล้างข้อมูลไซต์หรือเปลี่ยนเครื่อง ต้องนำเข้าใหม่)

**เวลา:** เลือกใช้เสียงจริงแล้ว เกมจะอ่านโจทย์และ A/B/C ก่อน จากนั้นเปิดเวลา **25 วินาทีเต็ม** ต่อข้อ นาฬิกาตอบจะยังไม่ลดระหว่างช่วงอ่าน เผื่อเวลาโหลด/เริ่มเสียง 1.4 วินาที ผู้เรียนสามารถส่งคำตอบก่อนได้โดยไม่เสียสิทธิ์

ถ้าไม่ได้นำเข้าเสียงจริง เกมยังเริ่มเล่นได้ตามปกติและจับเวลา 25 วินาทีทันที
