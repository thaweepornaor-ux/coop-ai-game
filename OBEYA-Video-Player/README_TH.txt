OBEYA VIDEO PLAYER — WINDOWS SINGLE EXE BUILD KIT
=================================================

เป้าหมาย
- ใช้งานบน Windows 10/11 แบบ Offline
- สร้าง OBEYA.exe ไฟล์เดียวจากวิดีโอและไอคอนต้นฉบับ
- เปิดด้วย Microsoft Edge / Google Chrome โดยอัตโนมัติ
- ไม่ต้องติดตั้ง Python, Node.js หรือ Web Server
- วิดีโอต้นฉบับไม่ถูกแก้ไข ตัดต่อ บีบอัด หรืออัปโหลด

สถานะที่ตรวจสอบได้
- มีซอร์ส HTML/CSS/JavaScript ครบสำหรับหน้า Title และปุ่มควบคุม
- มีซอร์ส Windows Launcher (C#) พร้อมระบบส่งวิดีโอผ่าน 127.0.0.1
- มีสคริปต์ Build สำหรับสร้าง OBEYA.exe บน Windows ด้วย .NET Framework ที่มากับระบบ
- ยังไม่ได้คอมไพล์และทดลองเรียก OBEYA.exe จริงในสภาพแวดล้อมของผู้ช่วย
- ควรทดสอบกับวิดีโอจริงก่อนใช้งานห้องประชุม

ไฟล์ในชุดนี้
1. OBEYA.html             — ตัวเล่นวิดีโอ HTML5
2. OBEYA_Launcher.cs      — Launcher + เซิร์ฟเวอร์วิดีโอภายในเครื่อง (HTTP byte-range)
3. BUILD_OBEYA.ps1        — สร้างไอคอน ICO หลายความละเอียด และคอมไพล์ EXE
4. BUILD_OBEYA.bat        — ดับเบิลคลิกเพื่อเริ่มสร้างไฟล์

การสร้าง EXE (ทำครั้งเดียว บน Windows 10/11)
1. ดาวน์โหลดไฟล์ซอร์สด้านบนเก็บไว้ในโฟลเดอร์เดียวกัน
2. วางไฟล์ OBEYA.mp4 ต้นฉบับไว้ในโฟลเดอร์เดียวกัน
3. วางภาพไอคอนจริงที่ส่งไว้ในแชทเป็น OBEYA.png (หรือชื่อ Cinematic OBEYA Play Icon.png)
4. ดับเบิลคลิก BUILD_OBEYA.bat แล้วตรวจสอบข้อความ BUILD SUCCESS
5. คัดลอกเฉพาะ OBEYA.exe ที่สร้างเสร็จไปไว้บน Desktop
6. ดับเบิลคลิก OBEYA.exe และตรวจสอบฟังก์ชันจริงด้วยตนเอง

หลังขั้นตอน Build: ผู้ใช้งานปลายทางต้องการเพียง OBEYA.exe เท่านั้น
ไม่มีไฟล์ MP4, HTML, PNG หรือ ICO ที่ผู้ใช้งานต้องวางข้าง EXE
แอปไม่ได้แตก MP4 เป็นไฟล์ชั่วคราว แต่สตรีมไบต์จากทรัพยากรใน EXE

ข้อจำกัด
- เครื่องที่ใช้สร้างต้องมี .NET Framework 4.x และ csc.exe ใน Windows
- เครื่องปลายทางต้องมี Microsoft Edge หรือ Google Chrome และ .NET Framework 4.x
- รองรับไฟล์ MP4 เท่าที่ Edge/Chrome เครื่องนั้นรองรับ codec ของไฟล์ต้นฉบับ
- EXE ที่คอมไพล์เองไม่ได้ลงนามดิจิทัล อาจมีการแจ้งเตือนจาก Windows SmartScreen
- ตัว Launcher ใช้งานเซิร์ฟเวอร์เฉพาะ 127.0.0.1 เท่านั้น ไม่ได้อัปโหลดวิดีโอ
- หากปิดหน้าต่างเบราว์เซอร์ Launcher จะปิดตัวอัตโนมัติหลังไม่มี heartbeat ประมาณ 8 นาที
- ปุ่ม MINIMIZE ในหน้าเล่น หมายถึงออกจาก Fullscreen แต่ยังคงเปิดวิดีโอ
- หน้า Title แสดงเฟรมแรกจากแท็ก video ที่หยุดอยู่ ณ เวลา 0:00
- การสร้างไฟล์ EXE ขนาดมากกว่า 410 MB อาจต้องการหน่วยความจำพอสมควร

ปุ่มควบคุม
START, PAUSE/RESUME, STOP, MUTE/UNMUTE, BACKWARD 15s, FORWARD 15s,
FULLSCREEN, MINIMIZE (exit fullscreen), EXIT (กลับ Title)
พร้อม Progress Bar, เวลา, เสียงต้นฉบับ และระบบแสดง/ซ่อนปุ่มขณะเล่น
